# EPUB build — *Local network growth* (3rd edition)

Reflowable **EPUB3** conversion of the full book (preface + 11 chapters), with all
math and figures rendered as images. The print sources in `../` are never
modified — every intermediate here is regenerated from them.

## Build

```sh
sh build-book.sh      # -> book-ebook.epub
epubcheck book-ebook.epub
```

The current build passes **EPUBCheck 5.3 (EPUB 3.3) with 0 errors / 0 warnings**.

Requires (all ship with TeX Live): `tex4ebook`, `make4ht`, `dvisvgm`, plus
`perl`, `python3`, `pdftoppm` (poppler), `zip`/`unzip`. Validation: `epubcheck`
(`brew install epubcheck`).

## Pipeline (`build-book.sh`)

1. **`mkbody.pl ../<chapter>.tex > <chapter>-body.tex`** — preprocess each chapter
   for tex4ht (see transforms below), extracting every TikZ picture to
   `figures/*.tikz`.
2. **Preface** — sliced out of `../main.tex` (between `\chapter*{Preface}` and
   `\tableofcontents`).
3. **`renderfigs.sh`** — compile the extracted TikZ figures to PNG via the
   `standalone` class (tex4ht cannot rasterise TikZ itself).
4. **`pdftoppm`** — rasterise the matplotlib data figures (`../figs/*.pdf`) to
   `figures/*.png` at 220 dpi (EPUB readers do not render PDF).
5. **`pdflatex` + `bibtex`** — generate `.aux`/`.bbl` so citations resolve.
6. **`tex4ebook -f epub3+dvisvgm_hashes`** — convert to EPUB3; every math/figure
   image becomes a deduplicated SVG.
7. **post-process** — `fixepub.py` merges `friends.css` and fixes EPUB3 validity;
   `svg2png.py` rasterises SVG → PNG (Kindle/KFX cannot take SVG); repack.

## `mkbody.pl` transforms (why each exists)

- **strip `adjustbox`** — a print-only device to fit the 5×8 column; EPUB reflows.
- **`align` → `equation`+`aligned`** — a top-level `align` becomes an HTML table
  of separately-scaled `\frac` images on Kindle; wrapping it renders one clean
  display image.
- **`alignat` → separate numbered equations** — collapsing to one `aligned` would
  drop all but the last `\label` (amsmath), breaking `\eqref`; one equation per
  row keeps every label.
- **`split` → `aligned`** — tex4ht's dvisvgm path overflows its save stack on
  `split`.
- **matplotlib `\includegraphics{figs/NAME.pdf}` → `figures/NAME`** — points at the
  rasterised PNG; width options dropped (CSS handles sizing).
- **TikZ + `netfig-*` extraction** — each picture is written out for `renderfigs.sh`.
- **`\input{tab-*}` inlined** — chapters 7--9 keep their master tables in
  `../tab-*.tex`, and those tables hold the motif glyphs; leaving the `\input`
  for LaTeX to resolve would hide them from the two transforms below.
- **`\ngon{k}`, `\sqdiag`, `\sqstub` → tikzpictures** — the motif-column glyphs are
  written in `../main.tex` with the `\tikz` short form, which the tikzpicture
  extraction does not match; rewriting them as environments sends them down the
  same path as every other figure. Without this the motif column comes out empty.

The `calculation` box is defined in `ebook-preamble.tex` as a `<div class="calcbox">`;
`\leavevmode … \EndP … \IgnorePar` keeps it valid block markup even when a box
directly follows a figure float.

## Files (tracked)

| file                 | role                                                          |
|----------------------|--------------------------------------------------------------|
| `build-book.sh`      | full pipeline → `book-ebook.epub`                            |
| `book-ebook.tex`     | driver: preamble + preface + all 11 chapter bodies           |
| `ebook-preamble.tex` | shared preamble (packages, palette, `calculation` box)       |
| `ebook.cfg`          | tex4ht config (SVG pictures)                                  |
| `friends.css`        | stylesheet — edit this, then rebuild                         |
| `mkbody.pl`          | per-chapter preprocessor                                      |
| `renderfigs.sh`      | compile extracted TikZ figures → PNG (`standalone`)          |
| `fixepub.py`         | post-build: merge CSS + fix EPUB3 validity                   |
| `svg2png.py`         | post-build: rasterise SVG → PNG                              |
| `book-ebook.epub`    | the deliverable                                              |

Everything else in this directory is generated and git-ignored (regenerated by
`build-book.sh`).
